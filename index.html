সম্পূর্ণ ফ্রি গাইড

কীভাবে ওয়েবসাইটটি নিজের নামে লাইভ করবেন এবং Facebook পেজে শেয়ার করবেন?

কোনো ডোমেইন বা হোস্টিং খরচ ছাড়াই মাত্র ৫ মিনিটে আপনার নিজের ই-কমার্স লিংক তৈরি করুন।

ধাপ ১: এই ওয়েবসাইটের ফাইলটি সেভ করুন

এই কোডটি কপি করে আপনার কম্পিউটার বা ফোনে index.html নামে সেভ করুন।

ধাপ ২: GitHub Pages-এ সম্পূর্ণ ফ্রি-তে আপলোড করুন

  1. github.com এ একটি ফ্রি অ্যাকাউন্ট খুলুন।
  2. New Repository তে ক্লিক করে আপনার শপের নাম দিন (যেমন: amar-shop-bd) এবং Public রেখে Create করুন।
  3. uploading an existing file এ ক্লিক করে আপনার index.html ফাইলটি আপলোড করে Commit করুন।
  4. Repository-এর Settings → Pages এ গিয়ে Branch হিসেবে main সিলেক্ট করে Save দিন।
  5. ১ মিনিটের মধ্যে আপনি আপনার নিজস্ব লাইভ লিংক পেয়ে যাবেন (যেমন: https://username.github.io/amar-shop-bd/)।

ধাপ ৩: আপনার Facebook Page-এ শেয়ার করুন

  • আপনার Facebook Page-এর Action Button (Shop Now / Learn More)-এ আপনার ওয়েবসাইটের লাইভ লিংকটি সেট করুন।
  • যেকোনো প্রোডাক্টের "বিস্তারিত" বাটনে ক্লিক করলে সেই নির্দিষ্ট প্রোডাক্টের আলাদা শেয়ার লিংক পাবেন—সেটি পোস্টের ক্যাপশনে দিলে কাস্টমার সরাসরি ওই প্রোডাক্টে এসে অর্ডার করতে পারবে!
